# Dependencies

## Runtime

| Package | Version | Purpose |
|---------|---------|---------|
| `three` | ^0.181.0 | WebGL 3D rendering stage for plates, floor, reflections, and captions |
| `gsap` | ^3.13.0 | Timeline-based transition tweening and animation curves |

## Development

| Package | Version | Purpose |
|---------|---------|---------|
| `vite` | ^7.1.12 | Build bundler and dev server; emits ESM (`vexy-stax.element.js`) and IIFE global (`vexy-stax.global.js`) |
| `@playwright/test` | ^1.56.1 | Headless E2E testing in Chromium; verifies render output and interaction |

## Node

Requires Node ≥18.0.0.
